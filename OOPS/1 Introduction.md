---- Access Modifiers---

Concept: These keywords define who can access the members (data and functions) of a class.
Private: Data is only accessible inside the class. By default, all members in a C++ class are private.
Public: Data is accessible from outside the class (e.g., from the main function).
Protected: Data is accessible inside the class and by derived classes (used in Inheritance), but not outside.
