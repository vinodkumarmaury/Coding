Definition: "Poly" means many, "Morph" means forms. It is the ability of an object/function to take on multiple forms.

Compile-Time Polymorphism (Static):

Constructor Overloading: Multiple constructors with different parameters.

Function Overloading: Functions with the same name but different parameters (number or type).

Operator Overloading: Customizing how operators (like +) work for user-defined classes (e.g., adding two String objects).

Run-Time Polymorphism (Dynamic):

Function Overriding : When a child class provides a specific implementation of a function that is already provided by its parent class.

Virtual Functions : A member function in the base class that you expect to override in derived classes. It ensures that the correct function is called for an object, regardless of the type of pointer used for the function call.
